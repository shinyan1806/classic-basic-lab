BASICのプログラム集

## Overview（概要）
趣味で作成した昔ながらの行番号付きBASICプログラムをまとめるリポジトリです。気分転換を兼ねて作成しており、徐々に増やしていけたらと思っています。

## Features（特徴）
- 行番号付きのクラシックなBASICプログラム
- 十進BASICでそのまま実行可能

## Getting Started（使い方）
1. 十進BASIC（[公式サイト](https://decimalbasic.web.fc2.com/)）をインストールしてください。
2. 本リポジトリをクローンまたはZIPダウンロードします。
3. プログラムを開き、実行してください。
